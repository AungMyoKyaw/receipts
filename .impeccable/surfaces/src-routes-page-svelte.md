# Receipts surfaces

Mode: Operate. Targets: the native timer popup and log window.

## Direction contract

THESIS: A proof of work, set in type. Port the user's v9 prototype, not the discarded dark starter UI or the prototype's component gallery.

OWN-WORLD: Cream proof paper, carbon ink, proofing red; Fraunces numerals at optical size 144, Inter notes and controls, JetBrains Mono measurements; crop marks, crosshairs, tear lines and a rotated date stamp.

STORY: Enter a work note, start recording in either window, stop once to save locally, and inspect the log, week or rolling statistics. Empty and error states remain honest.

FIRST VIEWPORT: The 320px popup contains status/open log, note, a 46px timer and Start/Stop. The 760px log window contains wordmark/date, today/week totals, a 42px timer strip, and three tabs. The calendar exposes the full time axis at normal window sizes and places off-hours recording above the grid.

FORM: Explicitly pinned by `prototype/README.md` v9 and the user's request to rewrite from it. No concept roll or generated comp applies. User screenshots at 01:38 required correcting doubled field focus, calendar height and off-hours visibility.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
